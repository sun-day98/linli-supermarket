## 一、原始需求复述

构建一套社区超市系统，把「用户购物」与「门店经营」放进同一套系统，让业务在 H5、微信小程序和管理后台之间保持一致。用户侧看到商品后能更快下单，门店侧获得更清晰的库存、履约与经营数据。

系统由四个部分组成，三类客户端共用同一套 Spring Boot REST API 与 MySQL 数据库：

- **Spring Boot 后端**：商品、购物车、订单、会员、优惠券、评价与运营接口；
- **H5**：面向移动浏览器的用户商城；
- **微信小程序**：覆盖同类购物流程；
- **Web 管理后台**：商品、库存、订单、会员与门店运营。

用户主旅程（H5）：浏览首页/分类 → 商品详情与加购 → 勾选结算 → 选地址与优惠券 → 金额试算 → 支付 → 门店配送 → 确认收货 → 发放积分并沉淀会员数据。本次交付为**演示环境**：微信/支付宝支付为模拟，不产生真实扣款；生产上线能力列入 P2/待办。

## 二、产品定义

### 2.1 产品目标（3 个，正交）

1. **统一购物闭环**：让用户通过 H5 与微信小程序，以同一套账户与数据完成「浏览→加购→结算→支付→收货」的完整链路，降低下单摩擦。
2. **门店经营可视化**：让门店在一个后台内掌握商品、库存、订单、会员、优惠券、配送与经营指标，支持快速决策（补货、上下架、发券）。
3. **交易可靠与一致**：保证金额试算准确，库存/优惠券/积分在订单状态流转中正确扣减与回滚，为生产上线预留一致性基础。

### 2.2 用户故事

1. 作为**社区住户**，我希望在手机上按分类浏览商品、查看规格/价格/库存并快速加购，以便足不出户买到日常所需。
2. 作为**社区住户**，我希望在结算时选择地址和优惠券、实时看到金额明细，并顺利完成支付，以便清楚知道花了多少钱、放心下单。
3. 作为**社区住户**，我希望在会员中心集中查看订单、积分、优惠券、收藏、地址和客服入口，以便统一打理我的账户与售后。
4. 作为**门店店长**，我希望在后台看到今日销售额、订单数、客单价、库存紧张商品与销售趋势，以便快速掌握经营状况并及时补货。
5. 作为**门店运营**，我希望维护商品、分类、优惠券、配送区域与门店设置，并让改动同步到 H5/小程序，以便让线上展示与经营策略保持一致。

## 五、核心业务规则

### 5.1 金额规则

- 商品金额 = Σ（商品单价 × 购买数量）。
- 配送费：订单商品金额达到「免配送门槛」时配送费为 0，否则按门店配置的配送费收取。
- 优惠金额 = 满足门槛的优惠券抵扣额（单笔订单限用一张券，见待确认 Q5）。
- **应付金额 = 商品金额 + 配送费 − 优惠金额**；结果保留两位小数。
- 提交订单时后端**再次校验**商品单价与配送费，以前端试算仅作展示参考。

### 5.2 库存规则

- 下单成功即扣减对应商品库存；取消订单/支付超时回滚库存。
- 库存不足时禁止下单并给出明确提示；库存紧张商品在后台突出显示。

### 5.3 优惠券规则

- 优惠券含类型、使用门槛、有效期、发放范围、核销状态。
- 下单时校验：券有效、在有效期内、属于当前用户、订单金额满足门槛。
- 支付成功即核销优惠券；取消订单时释放/回滚券状态。
- 支持新人自动发放。

### 5.4 积分与会员规则

- 任意符合规则的新手机号使用验证码 `123456` 登录即自动注册，并初始化地址等基础数据。
- 确认收货后按实付金额发放积分（默认 1 元 = 1 积分，见待确认 Q4）；积分明细可查。
- 取消订单/退款时同步回滚积分。

### 5.5 配送区域规则

- 配送区域按 城市 / 区县 维护，含启用状态与热门城市标记。
- 城市停用或其下无启用区县时，该区域不在 H5/小程序展示。
- 结算与下单时按收货地址所属区县校验可配送性，不可配送区域禁止下单。

### 5.6 订单状态流转

```
待付款 → 已付款/待配送 → 配送中 → 已完成（确认收货，发放积分）
   └────── 取消（回滚库存/优惠券/积分）──────┘
```

- 状态流转由后端统一控制，前端按状态展示可用操作。
- 待付款订单支持取消；超时未支付可自动取消（演示环境可模拟）。

### 5.7 并发与一致性（真实业务必须保证，演示环境可简化但需预留设计）

1. 库存扣减并发控制（防超卖）；
2. 支付回调幂等（防重复处理）；
3. 优惠券核销与订单状态事务一致；
4. 取消订单后库存 / 优惠券 / 积分正确回滚；
5. 提交订单时再次校验价格与配送费。

## 六、UI 设计草稿

- **H5 / 小程序**：移动端单列布局，底部 Tab 导航（首页 / 分类 / 购物车 / 订单 / 我的）；首页顶部为门店信息与搜索，中部为分类金刚区与热门商品卡片；商品详情底部固定「加入购物车 / 立即购买」操作栏；结算页为地址卡 + 优惠券选择 + 金额明细卡 + 提交按钮；会员中心为功能入口列表。
- **管理后台**：左侧菜单导航 + 顶部栏 + 内容区；数据概览为指标卡片 + 销售趋势折线图 + 最新订单表格；商品/订单等列表采用「筛选栏 + 数据表格 + 分页 + 操作列」，编辑用弹窗或抽屉表单；整体使用 Element Plus 组件与统一主色。
- **一致性**：三端展示的商品、价格、库存、优惠、配送信息均来自同一后端，字段口径一致。
